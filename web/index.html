Cloud Transfer Protocol.

Cloud Transfer Protocol (CTP) is a free and open-source data migration, synchronization, and streaming engine. CTP connects distinct cloud storage providers (Google Drive, Microsoft OneDrive, Amazon S3, Cloudflare R2, Backblaze B2, and local storage) to transfer files directly between clouds through volatile in-memory RAM buffers with zero local disk usage and end-to-end TLS 1.3 socket encryption.

// APPLICATION PURPOSE & GOOGLE DRIVE INTEGRATION

This website is a public informational landing page. No login, account creation, or registration is required to view any information about Cloud Transfer Protocol.

Why We Request Google Drive Permissions:
Users interact with Cloud Transfer Protocol through its open-source command-line interface (CLI). When a user initiates a cloud-to-cloud transfer involving Google Drive (e.g. migrating files from Google Drive to OneDrive or creating an off-site backup in Amazon S3), the application requests temporary Google OAuth 2.0 access strictly to read the user-selected files and stream them directly into the target cloud.

Zero Server-Side Storage:
Cloud Transfer Protocol does not operate intermediate storage servers or databases. All file bytes stream in volatile RAM ring buffers directly between the user's machine and Google's official API endpoints. OAuth tokens remain strictly on the user's local device.
